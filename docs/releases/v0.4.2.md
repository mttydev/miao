# miao v0.4.2

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.2.zh.md)

v0.4.2 reads the way Chinese does: the sidebar's usage labels now say 输入/输出/缓存 instead of the terse 入/出, and the labels that used to stay English no matter the language now follow it too.

## The usage labels read 输入/输出/缓存

The catalog now words the per-model header, the workspace 24-hour totals and the session usage grid with 输入 (input), 输出 (output) and 缓存 (cache); the activity rows (辅助调用, 子代理) use 输入/输出 as well. The workspace totals row, the per-model hover text and the status line hardcoded their English labels outside the catalog — they route through it now, so no label in the sidebar stays English on a Chinese system (#3249).

## The per-model header stays aligned

The header labels are CJK and own two cells per character, so the header now pads to the columns' display width — a format-width pad would have drifted 输入/输出/缓存 off the ASCII figures beneath them. The English catalog is byte-identical, so English screens and their tests are untouched (#3249).
