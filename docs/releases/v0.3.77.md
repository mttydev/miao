# miao v0.3.77

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.77.zh.md)

## Fixes

- **A long session compacts again.** The compaction trigger re-resolved the raw
  model window instead of the truncated input ceiling the request bound already
  used, so a 1M-window model at 393K input promised 880K of headroom and never
  compacted: every prompt re-sent the whole conversation while the interface
  read 94%. Trigger, request bound and percentage now share one ceiling
  (#3078).
- **One context percentage everywhere.** The desktop and web views added cache
  reads and writes on top of the input tokens and divided by the raw window, so
  the same session showed 120% where the TUI showed 16%. Both now read the
  engine's `contextBudget` (#3079).
- **A second screenshot pastes.** The clipboard handoff file is no longer
  deleted after the first read: each picture is served once by content hash and
  the host keeps rewriting the file, so the second paste no longer depends on a
  platform fallback that a pane may refuse (#3080).
