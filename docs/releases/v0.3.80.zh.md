# miao v0.3.80

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.80.md)

v0.3.80 降低从 Claude Code 迁移的成本；为崩溃中断的工具调用加装护栏；对重放流事件去重；并把竞品调研中的度量与性能项全部落地。

## 导入 Claude Code 会话（#3094）

`miao import-claude` 列出 Claude Code 保存在 `~/.claude/projects` 下的会话，可把其中一个导入为原生 Session——历史按文件顺序还原为对话正文——并报告 Claude 的设置文件。导入是显式动作，绝不自动运行；凭据文件永不读取：身份留在 Claude 那边。sidechain 轮次与纯工具记录会被计数并跳过；重复导入同一会话会跳过而不是复制历史。

## 重发的调用不再静默重复崩溃前的副作用（#3099）

工具执行中途被杀，会留下没有结果的工具行。引擎本就把它报告为 unknown outcome；现在每个工具行还携带内容指纹，此后第一次完全相同的调用会消费一次性护栏：模型收到指明先前尝试的纠正结果而不是执行，再一次相同调用则是它的知情选择。kill-mid-tool 测试会种下崩溃残留，证明副作用恰好执行一次。

## 重放的流事件会被去重（#3095）

第二个 `response.created` 或重复的已定稿调用不再终结整轮——两者都跳过并继续，与已定稿 reasoning 项既有的处理一致。

## 度量与性能（#3100、#3101、#3102、#3103、#3104）

- usage 遥测在报告、小时汇总、CLI `step_finish` 帧与 `miao usage` 中携带 cache-creation 与 reasoning 分桶；计价锚定 cache-write 与 reasoning 计费。
- 启动时并行的独立步骤、对已配置 provider 端点的有界预连接（不鉴权、失败静默、跳过 loopback）；工具面摘要只计算一次。
- `task_result` 支持有界等待 join 子会话，`task` 支持按任务指定模型，父会话压缩后仍可读取子报告。
- `script/eval.ts` 按轮次预算运行任务集，输出无偏 pass@k 与回归记录（tokens/成本/cache/策略）。
- TUI 改为增量 wrap 转录行，不再每次快照重排整个正文。
