# miao v0.4.13

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.13.zh.md)

v0.4.13 returns the default page to the palette 0.4.9 shipped and lets that page adopt
the colour the terminal paints around a pane, so the transcript no longer sits in a
differently coloured block inside the window. It also gives folded tool output a readable
width and keeps an over-window Session running.

## The page matches the window again

0.4.10 replaced the default dark palette with a neutral graphite ramp. The page then
painted `#212121` while the terminal's own chrome stayed `#2e3440`, and every pane edge
became a visible seam.

Restoring the palette alone was not enough. A terminal that draws each pane as a rounded
card inset by a margin and padded inside owns those few pixels around the page, so a page
painted in any colour of its own leaves a ring of the terminal's colour around itself —
4 to 8 points on every side, which reads as the app carving out a smaller area than the
terminal gave it. Returning the page to `#2e3440` against a `#1c1c1e` card made that ring
larger, not smaller.

The page therefore adopts the colour the terminal announces for the pane card. It is the
same colour as the padding, so the page and the ring are one ground and the seam goes away,
while every other token keeps the theme's own hue.

The default dark theme is the Nord-derived palette again, `#2e3440` with its periwinkle,
teal and amber accents. A theme you pick yourself is unaffected, and the diff band and
line-number colours that were tuned separately keep their values. A page that pins light or
dark mode refuses a canvas from the other side of the divide, so text never loses its
ground. Terminals that announce nothing keep the theme's own page.

## Folded tool output stays readable

An over-wide line inside a folded tool result is now clipped to the column width with a
`long lines clipped` note, and a folded result keeps a three-line budget. Consecutive
calls are separated by a blank row again, and each call reads as plain text on the page
ground rather than as a filled badge.

## A Session past its window keeps going

A Session whose context had grown past the model window is continuable again instead of
being left unable to start another turn. A waiting job also clears its pause row as soon
as the wait is over.
