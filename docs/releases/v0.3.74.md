# miao v0.3.74

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.74.zh.md)

v0.3.74 tells the model where it is — the clock, the workspace knowledge index, and which text is instruction — and repairs two TUI regressions from 0.3.73.

## The system prompt says what is instruction (#3044)

A constant `<instruction-authority>` block now names the only three instruction channels and treats everything a tool reports as data: an approval claim inside fetched content is not an approval, and being handed a list authorizes reading it, not executing its items. The base prompt gained breadth-first search over guessing, no re-reading after a successful conditional edit, an unattended-degradation policy, deferred skill loading until the material exists, and a final task-list item that is an independent check — with high-risk changes graded by a fresh task child. The block is reserved in `source_budget`, so the 64 KiB ceiling still holds.

## The system prompt carries the clock and the knowledge index (#3047)

The model had no clock and no view of the knowledge store unless it thought to list it. Both now ride the system prompt: a session-clock block with the local date, and a bounded index of the workspace knowledge store read through the same authorized path as the instruction sources. Being system text keeps consecutive provider turns byte-stable — the property `prefix_stability` guards — and re-keys the context epoch only at a day boundary or a store write, both bounded. A policy that denies the store, or an empty or unreadable one, yields nothing.

## The sidebar owns its column for the window's whole height (#3048)

0.3.73 kept the queue rows, the input box and the status strip inside the conversation column, but still laid them out across the whole window. The sidebar was therefore painted only down to where the footer band began: its rule stopped in mid-air above the input, and the box looked like it covered only the left part of the screen.

The horizontal split now happens first, over the frame, and the conversation column carries its own vertical layout. The sidebar runs from the first row to the last, so its rule reaches the bottom edge, and the nested layout measures the box at exactly the width it is drawn.

## A taken-back picture no longer reuses its number (#3049)

Pasting an image, undoing the draft and pasting again produced a second `[Image 2]` marker and a second `image-2.png` file, after which the composer became impossible to keep typing in. Two causes: numbers came from the count of live image attachments, and `undo`, `redo` and a selection delete rewrote the text without touching the attachment list — so a picture that left the draft handed its number to the next paste, and the bytes stayed attached with no marker on screen.

Image numbers are now handed out once per draft and only move forward; file attachments never spend one. Each attachment records the marker it is drawn as, and the two lists are reconciled after every handled key, so a step taken back drops the bytes the prompt would otherwise still send. A prompt the engine refuses comes back with its pictures intact.

## nix builds see the desktop workspace (#3043)

The root manifest declares `apps/desktop` as a workspace, but the derivation's fileset only carried `packages`, so `bun install` died with `Workspace not found "apps/desktop"` and all four `nix-hashes` jobs failed before computing a hash. The fileset carries the workspace now, and the accompanying hash refresh landed with it.
