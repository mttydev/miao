# miao v0.5.12

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.12.zh.md)

v0.5.12 is a patch that restores the solid rule between the conversation and the sidebar.

## A rule that read as a dashed line

The divider has been ASCII `|` since #3406. That change replaced the box-drawing `│` because a CJK console lays the character out over two cells, and a write over its second cell broke the rule on Windows. ASCII is one column under every width table, but its ink is shorter than the line box: each row ends short of the next, so the rule read as a dashed line.

## One rule that both consoles keep

The divider is the box-drawing `│` again. Its cell's symbol is `│ ` — the line plus a space — so the buffer declares the rule two columns wide. A CJK console that lays the glyph out over two cells then receives no write for the second one, and the glyph's own background covers it; on a terminal that gives the glyph one column, the trailing space paints that second cell. Nothing is laid out over either cell, and the rule is still carried every frame.
