# miao v0.3.86

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.86.zh.md)

v0.3.86 makes delegated work visible while it runs.

## A subagent stops being invisible

A child Session answers on its own, so the parent screen showed only the `task` tool's raw JSON and a usage total that counted the delegation after the fact: nothing said which child was still working, for how long, or what it had produced.

The sidebar now carries a `SUBAGENTS` block with one row per child — its short id, how long it has been running or that it is idle, how many messages it has produced, and what it was asked to do. Working rows read in the text colour, finished ones in the muted one.

A child's progress reaches the parent as no event at all, so the block re-reads itself through the engine's existing `jobs` answer: every two seconds while a child is busy, every ten while a turn is running (it may delegate at any point), and never on an idle Session with nothing delegated. A failed read leaves the block as it was instead of putting an error line over the conversation.

## The composer strip names them too

With the sidebar hidden there was still nothing in the left column, and a parent turn that had ended read a bare `Idle` while two children were still working. The strip now closes with the count — `Idle · 2 subagents`, `Working · 1 subagent · Esc interrupt` — only while a child is actually busy, and after whatever the turn itself is doing.
