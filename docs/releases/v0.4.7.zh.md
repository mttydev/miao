# miao v0.4.7

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.7.md)

v0.4.7 让主题列表在选择前就能看到效果，并让审批开关关掉后仍留在屏幕上。

## 主题列表实时预览

过去 `/theme` 在按 Enter 前什么都不变，从一列名字里挑 `kanagawa` 只能靠猜。现在光标每落到一行就立即重绘——背景、边框、侧栏和启动页一起切换。Esc 放回打开选择器时的主题；Enter 保留选择并写入偏好。dark/light/unlock 三行仍在 Enter 时生效，因为它们重载的是整套配色目录，而不是替换一个主题。

## 审批开关留在原处

合并状态行——以及 miao 自己绘制的状态条——过去只在自动批准开启时显示这一事实。按一下关掉策略，同时把唯一能再打开它的目标也移除了。现在这一事实始终存在：自动批准保留告警样式，默认模式显示"逐次批准"，两者带同一个和弦。无论开还是关，按它都能翻转策略。

## 本版还包含

两条视口回归保护：脱离跟随后的旧滚动偏移超出更短转录时，绘制尾部而不是空白窗口；在历史中打开另一个会话会跟随新会话的尾部（#3271）。

## 兼容性

无配置变化。主题与偏好的行为与之前一致；变化的只是写入时机——Enter，而不是每移一行。

## 维护与验证

`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 与 TUI 全量测试（767 条）在 Rust 1.100 stable 下通过。
