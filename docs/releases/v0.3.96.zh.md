# miao v0.3.96

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.96.md)

v0.3.96 不再让「暂停」这一行堆在对话里，并在 Windows 上退出时把终端还给你。

## 暂停是状态，不是消息

当后台工作仍在运行时，每一轮 drain 结束都会让 TUI 往对话里合成一行 `paused: waiting`。引擎在同一条件下每轮都会报告同样的停止，于是这一行被反复重建，看起来像一条永远不消失的消息——哪怕它旁边的那一轮早已结束。

这一行没有了。暂停原因改为显示在输入框标题上、和该轮的耗时并列（`Worked for 15.4s · paused: waiting`）；新一轮开始时这个位置被运行状态收回，而引擎自己写入历史的 `Task paused: …` 通知仍然保留完整说明。已经显示着这一行的会话，重新打开后就会消失。
