# miao v0.5.13

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.13.md)

v0.5.13 是一个修复版本：很长的会话历史不再拖慢启动，也不会在退出时打印一整面假的 root 错误。

## 启动时的遍历

`Runtime::construct` 会恢复每条记录过的会话 root。`main_checkout` 会对每一行都去问 git（`rev-parse --show-toplevel` 与 `--git-common-dir`）——主检出、子目录、非 git 目录，而它们都只可能回答 `None`。在一个有几百条历史会话的工作区里，每次启动就是几百个 `git` 进程，而且窗口关闭时这次遍历可能还没跑完。

## 只有 linked worktree 才问 git

只有 linked worktree 会把 `.git` 记录成一个指向 gitdir 的文件。`main_checkout` 现在对其它所有形态立即返回，一条 checkout 记录只花一次 stat，而不是一两个进程。

## 退出时不再逐条报告剩余会话

如果遍历还在跑时窗口关闭，阻塞池会取消正在进行的任务。tokio 把这种取消报告为 `background task failed`，而遍历会把它当成“root 不可用”逐条打印。现在被取消的阻塞任务会映射为 `ToolError::ShuttingDown`，恢复遍历直接停止，不再报告其实完好的会话。

## 验证

- 新增 `a_checkout_shaped_root_costs_no_git_process`：把一个会留下标记的 `git` shim 放进 `PATH`，断言 checkout 形状的 root 一个 git 进程都不会启动。
- Engine 的 CI 腿通过（Linux 分片与 macOS 编译腿）。
