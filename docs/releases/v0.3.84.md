# miao v0.3.84

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.84.zh.md)

v0.3.84 keeps automatic compaction working on long Sessions, and stops the streamed answer from breaking a sentence into pieces.

## Automatic compaction no longer switches itself off

A compaction pass summarizes the history one segment at a time. When a later segment timed out — or came back with text the engine could not use — the failure counted toward the three strikes that turn automatic compaction off for that Session, and the segments already summarized went with it. Three unlucky tails on a long history were enough to switch automatic compaction off for good, after which the window filled until every request was refused.

A pass that summarized at least one segment no longer counts against that breaker: it is reported as partial, and the next turn's pass tries the history again. A pass that produced nothing at all still counts, so a summarizer that genuinely cannot summarize stops instead of looping. The breaker is half-open too: it reopens one attempt once the history has grown a tenth past the size that failed, or after four settled turns, so a provider that was repaired is used again without an explicit `/compact`.

## The transcript shows where a compaction cut the history

A compacted Session used to look as if earlier turns had simply vanished. The transcript now prints `── conversation compacted · earlier turns summarized (N chars) ──` at the cut, so the boundary between what the model still sees and what it does not is visible.

## A streamed sentence stays one paragraph

A gateway that interleaves thinking with the answer delivers a couple of characters of prose, then the thought, then the rest of the sentence. Each switch opened a new paragraph, so the reply painted those first characters on a bullet of their own and continued below a `Thinking` header — text that looked cut off after one or two characters, several times a turn. Thinking that arrives mid-sentence now folds in above the paragraph it interrupted, and the prose keeps filling the same block.

## Also in this release

- **Reasoning effort follows the prompt** — with `auto_effort` enabled, a prompt that asks for more or less thinking selects the matching registered effort variant instead of leaving the Session's previous choice pinned.
- **A suggestion for the next prompt** — with `predict_next` enabled, an idle Session offers one line the operator can accept with `Tab`.
- **Version bumps roll over** — `bun script/set-version.ts --bump patch|minor|major` derives the next version, so a patch number never reaches 100.
- **A cancelled turn settles its tools** — tool calls an interrupted turn never ran now read as settled instead of keeping a running glyph forever.
