# miao v0.3.93

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.93.md)

v0.3.93 修掉一条在会话已经恢复后仍留在屏幕上的暂停行。

## 恢复后的会话不再声称自己还停着

一次分类停止会在输入框上方画一行 `⋯ context · engine`，内容为 `paused: <原因>`。这行表示的是状态而不是消息，但状态结束时没有任何东西把它撤掉：续跑只清了会话自己的字段，画出来的行留在原地；新一轮开始则两者都不清。于是，一条在后台任务运行期间暂停、随后自动恢复并完成下一回合的会话，会一直把 `paused: waiting` 和 “Worked for 6.2s” 摆在一起——看起来像它还停着。

现在这行的存在时间与状态完全一致：一个统一的清理函数同时清字段和那一行，并在循环重新武装、以及新一轮开始时执行。引擎注入的完整说明仍留在历史里，细节不会丢。
