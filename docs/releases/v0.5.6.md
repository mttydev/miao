# miao v0.5.6

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.6.zh.md)

v0.5.6 is a patch for the question panel: a typed answer now goes out when you
press Enter.

## Enter sends what you typed

When the `question` tool offered a typed answer — "type your own" — Enter never
sent it. The panel's Enter handling started typing on that row and always came
back true, so submitting was unreachable from it: after typing you had to leave
the row, and leaving it sent one of the listed options instead.

Enter now ends the typing and sends the answer in one key. With several
questions it advances to the next one, the same way an option answer does.

## Verification

`cargo test` in `crates/miao-tui` (846 library tests), `cargo clippy
--all-targets -- -D warnings`, and `rustfmt --check`. The new test drives the
real key path and fails without the change.
