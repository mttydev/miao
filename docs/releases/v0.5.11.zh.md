# miao v0.5.11

v0.5.11 修的是引擎已经把排队的提示词提升之后，它仍停在输入框上方那一条队列里。

## 一直不消失的队列

输入框上方那一条并不是单一列表：它是最近一次快照里的待处理列表，加上提示词在本地留下的回显，直到引擎结算它为止。被提升时，回显会保留到下一次投影把它撤掉——但这个顺序并不保证。携带已提升消息的那次投影可能先于提升事件到达，而它会按快照把回显丢掉，因为快照已不再把该输入列为待处理。此后没有任何东西重算这一条，于是已结算的提示词一直留在屏幕上，看起来像一条永远排不完的队列，直到别的操作重新打开会话。

## 结算时两处副本一起清掉

现在 `InputSettled` 会在同一个事件里同时丢掉回显和快照自己保存的那份该输入 id（连同它的待处理提示词行），再重算待处理数量并重绘这一条——无论投影与该事件谁先到。取消排队提示词的行为保持不变：立即重算这一条。

- `cargo fmt --check` 干净；发布提交由 `tui` 工作流（fmt、clippy 与测试）把关。
