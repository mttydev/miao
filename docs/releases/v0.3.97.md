# miao v0.3.97

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.97.zh.md)

v0.3.97 makes the context figure tell the truth after an automatic compaction.

## The context figure after a pass

A long Session compacts automatically, and the pass itself worked: a 614k-token prompt became a 22k-token one. The turn after it, however, still planned against the count reported before the pass. The sidebar showed the old figure beside a much smaller request, so the pass looked like it had freed nothing, and the next decision inherited that count.

The anchor now ignores usage reports from before the newest compaction. The usage event publishes the occupancy the request actually carried, taken from the provider's own count, and the window comes from the model's limits so a turn right after a pass still names the ceiling it ran against.
