# miao v0.5.17

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.17.md)

v0.5.17 是一个修复版本：长时间连续调用工具的会话也能自动压缩；空闲时提交的输入不再先显示成“排队”。

## 在工具边界压缩

此前压缩只在模型返回纯文本、没有工具调用的轮次运行。长时间的自主任务几乎每轮都调工具，压缩门根本没被评估：上下文可以涨到窗口（实测 99%）也不压缩，`/compact` 记录下来的请求也没有边界去执行。

现在“工具已结算”就是合法边界：切点落在最后一个 tool_result 之后，assistant 的 `tool_use` 与结果留在同一侧；存储层也接受“没有未结算调用”的 tool_result 边界。`/compact` 在同一处被读取执行。

## 空闲输入不再显示为排队

空闲时提交，会先把输入画进输入框上方的排队带，直到引擎把它 promote，看起来像在“排在空无之后”。现在空闲会话中仍在途的输入不再画进排队带；运行中的会话（真正的 steer）和已经排队的输入照常显示。

## 验证

- compaction 验收：第一次压缩切在工具边界，每个已结算轮次都提交 checkpoint。
- miao-engine 651 个 lib + 25 个相关集成测试；miao-tui 865 个 lib 测试；clippy 无告警。
