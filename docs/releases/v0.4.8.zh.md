# miao v0.4.8

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.8.md)

v0.4.8 补完侧栏的语言切换，并补齐了命令与 Provider 配置方面缺失的文档。

## 侧栏跟随所选语言

目标面板、计划/配额块、会话用量账本、活动计数和子代理行此前仍是英文，而 TUI 其余部分已跟随 `/lang` 选择。现在它们都从词表读取：`GOAL` / `PLAN · QUOTA` / `SUBAGENTS` 标题、目标与计划状态、步骤、预算、文件计数、配额重置倒计时、`no usage yet`、重试/尝试/返工计数，以及手动审批的底栏事实（`ask approval` / `逐次批准`）。

颜色改为按词表 key 选择，而不是按英文字符串匹配，所以中文界面保留与原文一致的警告色与强调色。

## 文档：FAQ 与命令参考

新增的 FAQ 页面回答了反复出现的问题——会话与恢复、上下文与压缩、权限与审批、Provider 密钥与路由；命令参考则在一处列出所有命令与快捷键。指南与 Provider 页面做了精简，改为指向这些页面而不是重复内容。

## 兼容性

无配置、协议或存储变更。既有主题、偏好与会话照常使用。

## 维护与验证

`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 与全量 TUI 测试（770 项）在 Rust 1.100 stable 上通过，包含中英文两种界面下的侧栏目标区测试。
