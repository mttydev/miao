# miao v0.4.5

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.5.md)

v0.4.5 补完合并状态行的最后一块：在 mtty 宿主下，终端把信息行彻底还给对话区——输入框保持贴底、不再有预留空隙——而宿主行上的每次点击，都会以操作员自己的快捷键送达，拼写随上报而行。

## 这一行属于对话

昨天的合并保留了一条隐形点击带：宿主瞄准记录的单元格合成鼠标事件。它能用，但读起来像输入框与 mtty 状态行之间浪费的一行。宿主模式下布局现在少一条带——对话区接管这一行——上报内容也改为"事实 + 各自回应的和弦"（`ctrl+x f` 翻转审批、`ctrl+x m` 打开模型选择器、`ctrl+x a` 打开 provider 列表），拼写取自键位表，重映射会随上报一起生效（#3264）。

## 审批翻转有了自己的键

合并行可以点击审批事实，所以翻转终于有了自己的和弦：`<leader>f`，与它同排在 mtty 行上的选择器/列表和弦作伴（#3264）。

## 兼容性

点击在所有组合下落点一致：携带和弦的 miao 直接发送指定按键；只上报单元格的 miao（0.4.3/0.4.4）仍走记录单元格的合成鼠标事件。零几何的上报会被拒绝而不是点到转录区。普通终端的绘制状态条完全不变。

## 维护与验证

CI 覆盖 `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 与 TUI crate 的全量 `cargo test`（760 绿），运行于 Rust 1.100 stable 工具链。
