# miao v0.3.86

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.86.md)

v0.3.86 让委派出去的活在进行时就看得见。

## subagent 不再是隐形的

子会话在自己的 Session 上作答，所以父会话这边此前只有 `task` 工具的原始 JSON，以及一个事后才累加的用量总数：没有任何东西说明哪个子会话还在跑、跑了多久、产出了多少。

侧栏现在有了 `SUBAGENTS` 区块，每个子会话一行——短 id、已经跑了多久（或显示空闲）、产出多少条消息，以及它被派的活。运行中的行用正常文字色，结束的转灰。

子会话的进度不会作为事件到达父会话，所以这个区块靠引擎现有的 `jobs` 应答自己重读：有子会话在忙时每两秒一次，回合进行中每十秒探测一次（回合随时可能发起委派），空闲且没有委派时完全不发请求。读取失败时保留原样，不会在对话上盖一条错误行。

## 输入框状态行也会点名

侧栏收起时左栏仍然什么都看不到，而且父回合已经结束、两个子会话还在跑时，状态行只写一个 `Idle`。现在状态行末尾会带上计数——`Idle · 2 subagents`、`Working · 1 subagent · Esc interrupt`——只在确有子会话繁忙时出现，且排在"这一轮本身在做什么"之后。
