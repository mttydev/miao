# miao v0.4.3

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.3.zh.md)

v0.4.3 finishes the sidebar's glow-up and makes its facts act like buttons: section headers pick up distinct syntax hues, the usage labels read 输入/输出/缓存, every remaining hardcoded chrome label joins the language catalog, the bottom strip's facts are clickable — flip auto-approve, open the model picker — with a press instead of a chord, and under the mtty host the strip merges into mtty's own status row.

## The status row merges into mtty

When mtty hosts the TUI, the window's bottom edge used to carry two lines: miao's facts under the composer, then mtty's own status row. miao now reports those facts to the host and paints nothing, so one row carries everything — the auto-approve policy, the model, the provider · protocol tail and the running build sit in mtty's bar as press targets beside the workspace path. A press there reaches the exact handler the painted strip used, delivered as a synthesized mouse report at the recorded cells, so nothing about the behavior changes. The host answers only when it can, and an older mtty never asks, so the strip keeps painting there; plain terminals are untouched, and the leader menu still owns the row while its chords wait (#3258, #3259).

## Clickable status strip

The bottom strip named the run's facts but a press on them started a transcript selection instead of acting. Clicking the auto-approve hint now flips the policy — the engine re-derives it through the same reload path a config reload uses and the strip relabels when the reply lands — and clicking the model label or the provider · protocol tail opens the model picker. Hit ranges are recorded as the footer paints, so remaps, translations and theme switches relabel the targets for free, and a strip taken over by the leader menu records no hits at all (#3254).

## Sidebar section headers carry their own hues

Each section header keeps its bold uppercase style but now carries a distinct syntax hue from the theme's code palette — 24H workspace keyword, session usage string, activity and subagents function, working tree kind, todos number, plan quota variable — so the column reads as structure instead of one gray wall. `NO_COLOR` and dumb terminals drop the tint to plain bold, and the English layout is byte-identical (#3251, #3252).

## The language catalog covers the rest

The status strip hints (no model, update ready, not following, switch account/model, hidden sidebar), the todo empty state, the leave-home notice, the approval panel's title and key line, and every list dialog's title and hint bar now route through the language catalog, closing the mixed-language UI on zh systems (#3253). `Lang::try_t` renders unswept strings raw instead of panicking on a missing key, and a guard test pins the swept labels to real Chinese renderings while keeping the English side byte-frozen (#3253).
