# miao v0.4.1

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.1.md)

v0.4.1 收尾图片输入与语言两方面的反馈：粘贴的图片在各条路由上都能送达 Volcengine 的 DeepSeek，被丢弃的图片会说明原因，macOS 上即使 shell 未声明语言，TUI 也以系统语言回答。

## 图片在各条路由上送达 Volcengine 的 DeepSeek

随安装附带的模型目录把日期化 id `volcengine/deepseek-v4-1-flash-261017` 标成纯文本，而 Ark 实际接受它的 `image_url` 分段并能描述图片（对着线上端点验证过）——于是凡是从目录快照构建的路由，都会把粘贴的图片替换成「model does not support image input」标记。修正该模态的自维护 overlay 现在直接在引擎自己的快照读取处生效，覆盖存储凭据路由与模型选择器清单，字段级合并语义与 `MIAO_MODELS_PATH` 精确目录规则都与 TS 侧一致（#3240、#3243）。在 `providers` 配置里按模型声明 `capabilities.input` 仍是自定义提供商的契约，现已配上视觉模型示例写入文档（#3241）。

## 被丢弃的图片会说明原因

当路由声明的输入模态不含图片时，模型收到的省略标记不再让人误以为图片已送达：它会指示模型告知操作者，并给出配置修复的名字（#3241）。

## macOS 以系统语言回答

macOS 上的 shell 常常不声明任何语言（`LANG=C.UTF-8`），TUI 此时会用英文回答。现在环境变量提供不了语言信息时，回退到系统的首选语言（#3238）。
