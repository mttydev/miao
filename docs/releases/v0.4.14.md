# miao v0.4.14

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.14.zh.md)

v0.4.14 keeps the default page on its own ground. The transcript is `#2e3440` again
whatever colour the terminal announces for a pane card, so it matches the window it sits
in instead of painting a darker block inside it.

## The page stops following the host card

0.4.13 let the page adopt `MTTY_TERM_BG`, the colour a terminal announces for the card
behind and around a pane. That closed the seam between the page and the pane's padding,
but it painted the whole transcript in the host's card colour: a window whose chrome is
`#2e3440` showed an `#1c1c1e` page, so the transcript no longer matched the window.

The page now keeps the theme's own ground, `#2e3440` for the default dark theme. The
Nord palette, the accents and the diff colours that 0.4.13 restored are unchanged, and a
theme you pick yourself behaves as before.

The padding the terminal fills around a pane is still the terminal's own colour: those
pixels belong to the host and a page cannot repaint them from inside the pane. With the
page back on `#2e3440` the transcript and the window chrome agree, which is the state
0.4.9 shipped.

## The queue depth is a chip

The band above the input that lists held prompts now opens with a filled `Queued (N)`
chip — the page colour on the warning hue. Each prompt row keeps plain text, and the muted
` · queued` suffix is gone because the chip already says the queue is holding them. Depth
now reads at a glance instead of being counted by eye.
