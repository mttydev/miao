# miao v0.3.95

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.95.md)

v0.3.95 让 Windows 上粘贴图片真正可用，并且在剪贴板响应很慢之后仍能继续用。macOS 行为不变。

## Windows 上粘贴图片

Windows 的读图桥接是一小段 PowerShell 脚本。它在真实截图上有四处失败：`powershell.exe` 不一定在 `PATH` 上、`Clipboard.GetImage` 需要 STA 线程、Explorer 里的“复制”给的是文件而不是位图、4K 截图转成 base64 后可能超过引擎 8 MiB 的附件上限。

现在优先使用 System32 的 `powershell.exe` 并回退 `pwsh.exe`，以 `-STA` 运行；没有位图时读取 file-drop 列表；超过 4 MiB 的截图先按 2400px 重编码为 JPEG。脚本十秒不返回就被杀掉，输出读取最多再等两秒，因此卡住的剪贴板占用者、或持有管道的孙进程，都不会让粘贴标志永久挂着——那正是此前“之后每次粘贴都静默”的原因。
