# miao v0.5.12

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.12.md)

v0.5.12 是一个修复版本：会话与右侧栏之间的分隔线恢复为连续实线。

## 为什么会变成虚线

自 #3406 起，分隔线改用 ASCII `|`。那次修改是为 CJK 控制台让步：`│` 会被算作两格，向第二格的写入会让这条线在 Windows 上断裂。ASCII 在所有宽度表里都是一格，但字形本身低于行框，每一行都比下一行短一截，于是线看起来是虚线。

## 两种控制台都能保持的一条线

分隔符回到制表符 `│`，并且该格的符号是 `│ `——线加一个空格——让 buffer 把这条规则声明为两格宽。CJK 控制台把字形铺成两格时，不会再收到覆盖第二格的写入，字形的背景自己盖住它；只把字形算一格的终端，则由尾部空格铺满第二格。两格之上都不再排任何内容，规则仍然每帧重绘。

## 验证

- `crates/miao-tui` 的 `cargo test --lib`：858 个通过，含 `the_rule_declares_the_two_cells_a_cjk_console_uses` 与 `the_diff_never_writes_over_the_rules_second_cell`。
- `cargo fmt --check` 干净；发布提交由 `tui` 工作流（fmt、clippy 与测试）把关。
- 在 macOS 上用 preview 构建目视确认：分隔线是一条连续实线。
