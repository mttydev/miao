# miao v0.3.82

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.82.zh.md)

v0.3.82 makes Remote Control something a host can serve: a resident engine, a sidecar that ships with the archive, an owner-only administration pipe, and a TUI window that publishes the Runtime it owns. The composer and the usage table also get their layout back.

## Remote Control is a host now (#3111–#3115, #3120–#3123, #3126)

The host contract names its capabilities and attachments (#3111); committed engine events are translated into the remote timeline (#3113), projected history replays behind it (#3112), and engine commands map onto host methods (#3114). A live host runner serves published sessions (#3115).

`miao serve --remote-host` starts that host beside a resident engine (#3120), and the release archive now ships the `miao-remote` sidecar (#3121). A host registers with its Hub account (#3122). `miao runtime access` answers mtty's private pipe with one JSON request on stdin, resolving a 0600 registration and refusing a non-loopback endpoint; the host serves the owner-only `POST /access` for status, sessions, invites, pending devices, approve, reject and revoke (#3123).

The TUI window can host Remote Control itself (`miao --remote-host <control.json>`), publishes the Runtime it owns to mtty as the pane's `runtime_context`, and removes its registration when the window stops (#3126). mtty's administration UI can therefore attest the window it is attached to instead of guessing another local Runtime.

## A calmer composer

The run state and its interrupt chord now sit at the composer's top-left (`Working · 2.1m · Esc interrupt`, `Idle`, `needs approval · bash`), while the model and any exception take a line of their own under the box; the border carries neither (#3124). The title stays readable once a run settles (#3117).

## Sidebar and release awareness

The 24H usage table now shares the Session rows' two-cell indent, its header sits over the name column, and the provider-group dash is gone; the sidebar no longer repeats the Session title and path the window chrome already shows (#3125). The TUI checks for releases at startup and while running (#3116).

## Fixes

- A submit-time clipboard probe no longer appends its text to the draft, so an orphan image marker cannot duplicate the prompt (#3129).
- Engine continuations it admits itself are attributed to the engine (#3118).
- Storage is not migrated under a live older process (#3110).
- iOS voice input starts reliably and explains failures (#3127).
