# miao v0.5.17

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.17.zh.md)

v0.5.17 is a patch that lets automatic compaction run during long tool-driven stretches, and stops an idle submission from appearing as a queued prompt.

## Compaction at a tool boundary

Compaction ran only on a turn that returned text without tool calls. A long autonomous run calls tools every turn, so the gate was never evaluated: the context could reach the window (99% observed) with no pass, and `/compact` recorded a request that no boundary answered.

A tool continuation is now a settled boundary once its results commit. The cut lands after the last tool result, so the assistant `tool_use` and its result stay on the same side of the summary, and the store accepts a tool-result boundary when no call is pending. `/compact` is read at the same boundary.

## An idle prompt is not queued

Submitting while idle painted the prompt in the queue band until the engine promoted it, which read as a prompt waiting behind nothing. The band no longer paints an input still in flight on an idle Session; a busy Session (a real steer) and already-queued inputs keep their rows.

## Verification

- compaction acceptance: the first pass cuts at the tool boundary, every settled turn commits a checkpoint.
- miao-engine 651 lib + 25 related integration tests; miao-tui 865 lib tests; clippy clean.
