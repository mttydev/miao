# miao v0.5.7

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.7.zh.md)

v0.5.7 is a patch for three problems: the sidebar rule on Windows, a wall of
errors on exit, and Markdown tables that were unreadable at any window width.

## The sidebar rule keeps its column

The rule between the transcript and the sidebar was painted with `│` (U+2502).
That glyph is East Asian Ambiguous: one column to `unicode-width`, two to a CJK
console — the Windows console ConPTY hosts miao in. The console stored the rule
across its own cell and the sidebar's first cell, and re-encoding or overlaying
that row dropped the rule again. That is the broken, near-white line, and the
one-to-three-column drift into the sidebar while scrolling.

The rule is now ASCII `|`, one column under every width table, and every frame
carries it, so a row the terminal dropped heals on the next draw. Earlier fixes
changed the glyphs around the rule and the repaint strategy; none of them
changed the ambiguous glyph itself.

## Exit no longer reports Sessions that are fine

Every exit printed one line per historical Session:

```
miao-engine: Session ... is unavailable (file IO failed: background task failed); leaving it at the engine root
```

Startup re-registered every recorded Session root, and each registration ran
one or two `git rev-parse` processes. On a long-lived workspace that walk was
still running after the window opened; closing the window dropped the tokio
runtime under it, the blocking pool was cancelled, and every remaining row
reported the cancellation as an unavailable root.

Sessions recorded at the engine root need no entry: an unregistered Session
already resolves to that root. Startup now restores only worktree placements,
which is the information the fallback cannot reproduce; a resumed Session is
registered by `Runtime::initialize` when it actually starts, and a worktree
removed outside miao is still re-homed.

## Tables fit the pane and explain themselves

A table was painted as one pre-formatted line per row, with every column capped
at 40 cells, and then wrapped as prose. A cell was folded in half, the grid
lost its columns, and the table stayed narrow even in a wide window.

Columns now use the width the pane actually has: real widths when they fit, a
water-fill shrink when they do not, one `…` per clipped cell, and the same
separator columns in the header, rule and body. Table rows never go through the
prose wrapper.

Hovering a row shows the whole row in a floating panel, each cell labelled with
its column name. The tip follows the pointer and clears when it leaves the row
or the window loses focus.

## Verification

`cargo test` in `crates/miao-tui` (854 library tests) and in `crates/miao-engine`
(640 library tests, plus the placement and startup suites), `cargo clippy
--all-targets -- -D warnings`, and `rustfmt --check`. The new tests fail without
the changes: a rule wider than one column under a CJK width table, a table row
folded by the prose wrapper, a hover region outside the table columns, and a
startup walk that spawns git per recorded Session.
