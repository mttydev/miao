# miao v0.3.87

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.87.zh.md)

v0.3.87 makes a stopped Session say why it stopped, and separates a real block from a refusal to decompose.

## A blocked checklist no longer parks a Session silently

An empty runnable todo list is ambiguous on its own: the work may be finished, the list may be empty, or every remaining item may be blocked. The continuation loop read all three the same way, so a goal that was still `active` could sit with nothing moving it until the operator typed again.

`blocked_work()` answers the third case, naming each blocked item and the dependencies it is still waiting on. When a goal is active and nothing is runnable, the engine now admits **one** continuation that names the first blocked item and what would unblock it, records `loop.stopped` / `loop.blocked` / `loop.continuation`, and never repeats it for the same todo list — the existing stall and no-progress guards still bound the loop.

## A real block is not a refusal to decompose

`blocked_on_external_work()` classifies a recorded block by its evidence. Hardware down, power off, a credential or approval a human holds, a third party that is unavailable: that is a block. "Too large for one reply", "too complex", "needs many steps": that is a refusal to decompose, and scope language wins when both appear.

## Spec: what a finished turn means

`specs/anti-splitting.md` fixes the predicate a drain must satisfy before it may end - no active goal, no runnable todo, no plan step without a completed todo, no unfed blocked item - with per-signature idempotency so a continuation can never repeat, and deliverable-level plan granularity so the gate cannot be satisfied with micro-steps.

## What is not in this release

The request-scoped whole-task note was reverted before release: injecting it into every ordinary request changed the request shape the goal loop's fixtures script against. The contract it expressed is not enforced by this build; the predicate in the spec is what will enforce it.
