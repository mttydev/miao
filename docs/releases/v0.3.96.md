# miao v0.3.96

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.96.zh.md)

v0.3.96 stops the pause line from piling up in the conversation, and gives the terminal back on Windows when miao exits.

## A pause is a state, not a message

When a drain ended while background work was still running, the TUI synthesized a `paused: waiting` row into the transcript. The engine reports the same stop at the end of every drain, so the row was rebuilt again and again and read as a message that never cleared — even beside a turn that had already finished.

The row is gone. The pause now rides the composer title beside the turn's duration (`Worked for 15.4s · paused: waiting`), a running turn takes that title back, and the engine's own `Task paused: …` notice still carries the detail in history. Sessions that already show the row lose it when they are reopened.

## The terminal comes back on Windows

miao now leaves the alternate screen before it exits on Windows, so the shell and its scrollback are restored instead of the console staying on the last frame.
