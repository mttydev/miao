# miao v0.3.80

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.80.zh.md)

v0.3.80 lowers the switching cost from Claude Code, hardens crash-interrupted tool calls, deduplicates replayed streams, and closes the measurement and performance items from the competitive research.

## Import Claude Code sessions (#3094)

`miao import-claude` lists the sessions Claude Code keeps under `~/.claude/projects`, imports one as a native Session whose history is the conversation prose in file order, and reports Claude's settings file. Import is explicit — nothing runs on its own — and credential files are never read: identities stay with Claude. Sidechain turns and tool-only records are counted and skipped; a repeat import skips with the existing Session instead of duplicating history.

## A re-issued call cannot silently repeat a crash (#3099)

An interpreter killed mid-tool leaves its tool row without a result. The engine already reported that as an unknown outcome; now every tool row also carries a content fingerprint, and the first later identical call consumes a one-time guard: the model settles a corrective result naming the earlier attempt instead of executing, and the next identical call becomes its informed choice. A kill-mid-tool test seeds the durable crash residue and proves the side effect runs exactly once.

## Replayed stream events are deduplicated (#3095)

A second `response.created` or a duplicate finalized call no longer kills the turn — both skip and continue, matching the treatment finalized reasoning items already had.

## Measurement and performance (#3100, #3101, #3102, #3103, #3104)

- Usage telemetry carries cache-creation and reasoning buckets through reports, hourly rollups, the CLI `step_finish` frame, and `miao usage`; pricing pins cache-write and reasoning billing.
- Startup joins its independent steps and prewarms configured provider connections on a detached, bounded task (no auth, failures silent, loopback skipped); the tool-surface digest is computed once.
- `task_result` joins background children with a bounded wait, `task` accepts a per-task model, and a compacted parent can still read a child report.
- `script/eval.ts` runs task sets with per-trial budgets and reports unbiased pass@k with regression records (tokens/cost/cache/policy).
- The TUI wraps transcript rows incrementally instead of re-wrapping the whole body per snapshot.
