# miao v0.4.16

v0.4.16 让侧栏的上下文进度条真正可读。0.4.15 新增的这条进度条把实心段和空槽画成同一种颜色，于是任何读数看着都像满格；它还会把小比例取整成零格。

## 进度条如实表示窗口占用

这一行给出分数——`上下文 105.0k / 967.2k · 10%`——旁边的进度条存在的意义就是让人不必心算就能回答「离压缩还有多远」。两个缺陷让它答不上来：

- **两段共用一种颜色。** 实心段和空槽被合并成一个同色的 span，于是任何读数都画成一整块实心，占了一成的窗口和占满看起来完全一样。
- **小比例被取整成零格。** 实心格数做了整数截断，而进度条最窄只给六格，因此在窄侧栏上，百分之十七以下的读数全部填零格：进度条空着，旁边的数字却说窗口已经用掉一成。

现在两段用不同的颜色——实心段用 accent，达到或超过百分之八十转为 warning，空槽用主题里更暗的 element 色——并且任何非零占用至少填满一格。进度条因此会随旁边的百分比一起变化，读它比读数字更快。

窗口上限未知时依然不画进度条，因为没量到的窗口不等于满窗口。
