# miao v0.3.81

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.81.md)

v0.3.81 把原生 iOS 客户端变成一个真正可用的远程工作台；长会话改为从尾部打开，不再重放全部历史；TUI 的 diff 视图保留代码着色。

## iPhone / iPad 上的远程工作台（#3108）

iOS App 现在会记住上次的 tab、电脑与会话；iPad 默认展开侧栏，并支持外接键盘快捷键。会话列表显示相对活动时间、待审批与待回答、置顶状态，以及未被静音的待办数；App 图标角标使用同一聚合值。下拉刷新、自动分页与滑动操作取代了藏在长按菜单里的入口。

新建会话会立即进入；发送时先在本地显示消息，等待宿主确认接纳。失败或结果不明的消息会保留气泡：传输失败可用同一 operation ID 重试，结果不明则只核对、不自动重发。连接、错误与待处理提示在滚动时保持可见，停止按钮位于导航栏。

时间线现在显示工具状态、耗时与失败；助手消息显示 token、成本与首字延迟；diff 按文件分组并显示 +/- 行数。对话可复制或导出。消息搜索移出主线程；语音输入增加时长、取消、语言选择与音频中断处理；通知打开有进度提示；`miao://session/<host>/<session>` 可直接打开会话；支持本机会话静音。

附件与命令入口由宿主能力声明门控：只有连上的电脑声明支持时才显示。可选的 prompt 附件契约写在 `RPC-PROTOCOL.md`；未声明该能力的宿主保持原来的纯文本行为。

## 长会话从尾部打开（#3106）

过去打开会话会从 sequence 0 重放整个事件日志。一个五天、13,612 条消息、89,414 个事件的会话两分钟都打不开。TUI 现在只读最新一页消息，并只重放该窗口内的事件；向上滚动时再请求更早的一页。同一个会话从 21.7 MB / 89,414 个事件降到 338 KB / 1,302 个事件、200 条消息即可打开。

## diff 的颜色属于代码（#3107）

TUI 的变更视图过去只给 `+`/`-` 标记上色，代码本身是单一颜色。现在标记与正文共用转录的语法渲染器，变更行还会把 diff 色带铺到窗格边缘；桌面时间线默认展开编辑 diff。
