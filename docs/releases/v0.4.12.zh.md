# miao v0.4.12

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.12.md)

v0.4.12 修复 ChatGPT OAuth 与新模型背后的模型目录查找。目录缓存里其实已经有 GPT-6.2 Astra 和 GPT-6.2 Sol，但引擎读的是安装包里的旧快照。

## 最新的目录优先

安装包自带的 `models.json` 与目录服务的缓存可能同时存在。旧逻辑取第一个可读文件，于是旧安装快照一直压过服务已经刷新过的缓存；没有可用目录时，ChatGPT 账号路由自然没有模型可列。

引擎现在选择最新的可读快照。显式设置 `MIAO_MODELS_PATH` 仍会选中那一份精确目录；只有未显式指定时才会应用引擎自带的覆盖表。

## Windows 能找到缓存

Windows 原生进程通常有 `USERPROFILE` 而没有 `HOME`。查找目录现在在 Windows 上优先使用 `USERPROFILE`，再回退到 `HOMEDRIVE`/`HOMEPATH` 和 `HOME`，因此引擎读取的正是产品写入的同一份缓存。

升级后，ChatGPT OAuth 路由和模型列表会使用当前快照，包括 GPT-6.2 Astra 与 GPT-6.2 Sol，无需手动重装模型目录。
