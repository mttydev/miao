# miao v0.3.95

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.95.zh.md)

v0.3.95 makes pasting a picture work on Windows, and keeps it working after a clipboard that is slow to answer. macOS is unchanged.

## Pasting a picture on Windows

The Windows image bridge runs a short PowerShell script. It failed on real captures in four ways: `powershell.exe` is not always on `PATH`, `Clipboard.GetImage` needs an STA thread, an Explorer "copy" carries a file rather than a bitmap, and a 4K screenshot's base64 can exceed the engine's 8 MiB attachment bound.

The bridge now prefers the System32 `powershell.exe` and falls back to `pwsh.exe`, runs with `-STA`, reads the file-drop list when no bitmap is present, and re-encodes a screenshot over 4 MiB to a 2400px JPEG before sending it. A script that never answers is killed after ten seconds, and the output drain waits at most two more, so a wedged clipboard owner or a grandchild holding the pipe cannot leave the paste flag set for the rest of the Session — the failure that made every later paste silent.
