# miao v0.3.94

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.94.zh.md)

v0.3.94 finishes the loop-control cleanup: a read-only investigation is not a stalled Session, compaction stops charging a reply twice, and the divider between the transcript and the sidebar survives every row.

## A read-only investigation is not a stalled Session

The no-progress guard counted a turn as idle whenever it dispatched no mutating tool, so opening a new file every turn still looked like an idle reply and could be stopped after two turns. It now shares the signal the stale-list and flat bounds already use: a tool call the Session had not made before is work. A genuinely text-only reply still reaches the stop after two turns, and the operator's next message resets the identical-call leash as a whole — the refusal count no longer outlives the repeat count it belongs to.

## Compaction stops charging the reply twice

The context anchor summed the provider's input and output tokens, but input already covers the whole prompt, and the message marker was taken before the reply landed. The reply was then counted a second time as pending, so every boundary compacted one reply early — negligible on a large window, material on a small one. The anchor now counts the prompt alone.

The compaction breaker also calls itself a streak of consecutive failures, but a pass that committed left the half-open allowance in place: one later rejection re-tripped a breaker that had just succeeded, and the stored breaker never went idle. A committed pass now clears the streak.

## The divider is painted last

On Windows the rule between the transcript and the sidebar came back with gaps, and rows that reached the pane edge left their colour in it. The rule is the boundary between the columns, not part of either one, so it is now the last paint of the frame: one column, page background, every row. Nothing rendered into either column can break it or tint it.
