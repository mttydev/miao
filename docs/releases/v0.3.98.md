# miao v0.3.98

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.98.zh.md)

v0.3.98 repairs the Windows terminal's gapped divider and stray glyphs, and runs approval-free by default.

## Windows terminal rendering

Three reports from real Windows hardware traced back to two renderer defects. The divider between the conversation and the sidebar painted with gaps, and characters drifted one column to the right of where they belonged — a wide CJK glyph advances the terminal cursor two columns while the crossterm backend predicted one, so every changed cell printed after it landed one to the right. That was the detached "blue slash", the missing `继续追加` text, and chat rows painting across into the sidebar. Frames are now emitted in runs that end after a wide glyph, so the cursor resyncs at the true cell (#3219), and the divider refuses wide glyphs in its two boundary columns (#3215). Two smaller leaks in the same family: markdown hard-break backslashes painted literally at line ends and now consume quietly (#3219), and tool output echoed from inside tmux leaked the payloads of DCS, SOS, PM, and APC escape sequences, which the scrubber skips up to their terminator (#3222).

## Approval-free by default

Tools run without asking by default — the same classifier-guarded relaxation `--auto` carried, now without needing the flag. `--ask` restores per-call approvals, and operator deny/ask rules stay authoritative either way (#3225).

## Mobile and localization

Android and iOS follow the system language, with Simplified Chinese as the source and English translated (#3218, #3220, #3223), and the LocalAgent runtime messages join the sweep (#3227); iOS allows local tools by default (#3224); Android surfaces a background keep-alive reminder (#3211), follows the system wallpaper through Material You (#3212), and mobile sessions show queued prompts with share, copy and export (#3213).
