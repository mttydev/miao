# miao v0.4.0

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.0.zh.md)

v0.4.0 makes the TUI speak the operator's language, shows automatic compaction while it runs, arms it at 95% of the context window, and stops `read_file` from erroring on large files. It is also the first release under the 99-carry rule: `0.3.99` carried to `0.4.0`.

## The interface speaks Chinese and English

The TUI's own labels now follow the operating system language — the sidebar's in/out/cache columns, session usage and activity rows, the todo list (待办), the working-tree block, the composer's status line, placeholders and Thinking row, and the `/lang` command to switch between `en`, `zh`, or hand back to the locale (`auto`) at any time. The choice persists in `tui.json`, and the catalog keeps every label's English form byte-identical so keyboard-habit tests keep passing (#3236).

## Automatic compaction is visible

A compaction pass longer than 30 seconds turns the composer spinner warning-colored, the completion banner paints in the warning color with bold text ("context compacted · earlier turns summarized (N chars)"), and a compaction the transcript just gained announces itself once in the composer — re-played snapshots from a transport resync stay quiet (#3235).

## Compaction arms at 95% of the window

The declared-window trigger used to arm at 88%, so a heavy day stopped with a third of the window unread — the operator's logs showed sessions peaking at 99.3% of the *threshold* and still skipping. It now arms at 95%, Codex's effective ceiling and just under Claude Code's ~96.7% on 1M windows, leaving the summarizer its headroom (#3233).

## Large files read whole, as a window

`read_file` on a 32 KiB–1 MiB source no longer errors ("file is N bytes, above the 32768-byte whole-file bound") — a 635-line Python file is ~36 KB, so every moderately large file paid an error-and-retry turn. It returns the first window with `truncated`/`total_lines` and a note naming the bound, and `offset`/`limit` continue from there. Context assembly's probes keep their recorded skip, and reads above 1 MiB still refuse (#3234).
