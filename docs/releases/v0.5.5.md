# miao v0.5.5

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.5.zh.md)

v0.5.5 is a patch for the rule between the transcript and the sidebar. It was
drawn in the colour of secondary text, so it read as a white line down the page.
It also sat close enough to the transcript's last column that the Windows console
could print it one column off, and during a fast scroll it landed inside the
sidebar. It is now a calm frame edge that nothing else can reach.

## The rule is a frame edge, not text

The rule used `textMuted` (#b9b9b6 in the default theme), the colour of
secondary text; every other frame edge — the composer's box included — uses
`border`. It now uses that border colour, so it reads as an edge instead of a
bright line.

## Nothing is laid out beside the rule

The conversation column used to end right at the rule, so a glyph in its last
column could reach the rule's cell. That is not miao's decision alone: the
Windows console re-encodes the screen for the terminal and prints a dirty cell
as a continuation of the row it has just repainted, so a glyph the console
counts wider than the terminal does shifts that print. The conversation now ends
one column short of the rule, and the divider owns the empty column as well as
the rule, so no pane is laid out there. Wide glyphs that end in that column are
kept; the divider no longer erases them.

## A scroll frame does not repaint the rule

The rule used to be forced into every frame so that a row the terminal dropped
would come back. Next to a repainted transcript row that is exactly what made it
land off its column on Windows. It is now forced only into frames that do not
move the transcript: the frame after a scroll leaves it alone, and the quiet
frame after that carries every row again, which is also what heals a dropped
row.

## Verification

`cargo test` in `crates/miao-tui` runs the library tests and every PTY suite;
`cargo clippy --all-targets -- -D warnings` and `rustfmt --check` are clean. The
colour and the empty column have regression tests that fail without the change.
The repaint timing is a mitigation for the console's re-encoding; confirming it
needs a Windows ConPTY session, which CI does not run.
