# miao v0.5.13

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.13.zh.md)

v0.5.13 is a patch that keeps a long session history from slowing startup and from printing a wall of false root errors on exit.

## The startup walk

`Runtime::construct` restores every recorded Session root. `main_checkout` asked git (`rev-parse --show-toplevel` and `--git-common-dir`) about every row — the checkout, a subdirectory, a non-git directory — all of which could only answer `None`. On a workspace with hundreds of historical Sessions that was hundreds of `git` processes per start, and the walk could still be running when the window closed.

## Only a linked worktree asks git

A linked worktree is the only shape that records `.git` as a file naming its gitdir. `main_checkout` now returns immediately for every other shape, so a checkout row costs a stat instead of one or two processes.

## A quit no longer reports every remaining Session

If the window closes while the walk runs, the blocking pool cancels the in-flight work. tokio reports that cancellation as `background task failed`, and the walk printed it as an unavailable root for each remaining row. A cancelled blocking worker now maps to `ToolError::ShuttingDown`, and the restore walk stops instead of reporting Sessions that are fine.

## Verification

- New `a_checkout_shaped_root_costs_no_git_process` puts a logging `git` shim on `PATH` and asserts a checkout-shaped root starts none.
- The Engine CI legs pass, including the Linux shards and the macOS compile leg.
