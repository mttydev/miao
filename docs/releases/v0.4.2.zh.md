# miao v0.4.2

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.2.md)

v0.4.2 让用量标签按中文习惯说话：侧栏用量标签改说 输入/输出/缓存（不再是简单的 入/出），此前无论语言设置如何都固定英文的标签现在也跟随语言了。

## 用量标签读作 输入/输出/缓存

词表现在为每模型表头、工作区 24 小时汇总与会话用量栅格说 输入（input）、输出（output）、缓存（cache）；活动区的辅助调用、子代理两行同样改用 输入/输出。工作区汇总行、每模型行的 hover 文案与状态行此前把英文标签硬编码在词表之外——现在都路由到词表，中文系统下侧栏不再有英文残留（#3249）。

## 每模型表头保持对齐

表头标签是 CJK，每字符占两列，因此表头按列的显示宽度填充——按字符数的填充会让 输入/输出/缓存 漂离其下的 ASCII 数字。英文词表逐字节不变，英文界面与相关测试不受影响（#3249）。
