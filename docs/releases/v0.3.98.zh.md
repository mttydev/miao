# miao v0.3.98

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.98.md)

v0.3.98 修好了 Windows 终端的分割线断口和漂浮字符，并且默认免审批运行。

## Windows 终端渲染

来自真实 Windows 硬件的三份报告追溯到两个渲染器缺陷。会话与侧栏之间的分割线带断口，字符整体向右漂移一格——CJK 宽字符会让终端光标前进两列，而 crossterm backend 只预测一列，同一帧里宽字符之后的每个变更格都落在右边一列：那就是漂浮的「蓝色斜杠」、凭空消失的「继续追加」、以及画进侧栏的正文。现在帧按「宽字符即分段」的方式发射，光标在真实格位重新同步（#3219）；分割线自身的两列边界也不再容纳宽字符（#3215）。同族的两个小泄漏：markdown 硬换行的行尾反斜杠会画成字面量，现在静默消费（#3219）；从 tmux 里回显的工具输出会泄漏 DCS、SOS、PM、APC 序列的 payload，清洗器现在跳到终止符为止（#3222）。

## 默认免审批

工具默认直接执行——与 `--auto` 相同的分类器守卫放宽，不再需要旗标。`--ask` 恢复逐次审批，操作者的 deny/ask 规则在两种模式下都保持权威（#3225）。

## 移动端与本地化

Android 与 iOS 跟随系统语言，以简体中文为源、翻译英文（#3218、#3220、#3223），LocalAgent 的运行时文案一并本地化（#3227）；iOS 默认允许本地工具（#3224）；Android 显示后台保活提醒（#3211）、通过 Material You 跟随系统壁纸（#3212）；移动端会话展示排队提示，并支持分享、复制与导出（#3213）。
