# miao v0.5.9

v0.5.9 修的是滚动之后可能残留的一个字符。

## 滚动之后留下的东西

滚动几次之后，上一帧的字形可能停在某一行的右端。被移动的行确实重画了，但终端丢掉的那一格再也不会被补发：ratatui 的差异比较只对照它自己上一帧的缓冲，而那份缓冲仍以为该格已经画过。问题来自 Windows——控制台会把交给终端的屏幕重新编码，重编码时可能丢格。

## 滚动停下后重发一次

现在每次视口移动都会在最后一次移动的 200ms 之后安排一次整帧重绘：滚轮、PageUp/PageDown、Home/End、单行微调、切换会话，以及提交提示词后跳回末尾。这次重绘会清空 ratatui 的两份差异缓冲而不是清屏，因此每个单元格都会重发且不会有空白闪烁；连续滚动只在结束时付出一次整帧的字节量，而不是每一格一次。

- `crates/miao-tui` 的 `cargo test --lib`：855 个通过，含 `a_settled_scroll_asks_for_one_seamless_full_repaint`。
- `cargo clippy --all-targets -- -D warnings` 与 `cargo fmt --check`。
