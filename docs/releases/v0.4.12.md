# miao v0.4.12

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.12.zh.md)

v0.4.12 fixes the model catalog lookup behind ChatGPT OAuth and newly released models. The catalog cache already carried GPT-6.2 Astra and GPT-6.2 Sol; the engine was reading an older shipped snapshot instead.

## The newest catalog wins

The installer's `models.json` and the catalog service's cache can both exist. The engine used the first readable copy, so a snapshot shipped with an older build kept winning over the cache the service had already refreshed. With no catalog the ChatGPT account route had no models to expose.

The engine now takes the newest readable snapshot. An explicit `MIAO_MODELS_PATH` still selects one exact catalog, and the self-maintained overlay applies only when no explicit path is set.

## Windows finds the cache

On Windows a native process often has `USERPROFILE` but no `HOME`. The lookup now prefers `USERPROFILE` on Windows, with `HOMEDRIVE`/`HOMEPATH` and `HOME` as fallbacks, so the same cache the product writes is the one the engine reads.

After upgrading, ChatGPT OAuth routes and the model list use the current snapshot, including GPT-6.2 Astra and GPT-6.2 Sol, without reinstalling the model catalog by hand.
