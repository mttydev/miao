# miao v0.3.82

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.82.md)

v0.3.82 让 Remote Control 真正成为宿主能力：常驻引擎、随安装包分发的 sidecar、仅所有者可用的管理管道，以及由 TUI 窗口自己托管并发布 Runtime。输入框和用量表的布局也一并收紧。

## Remote Control 成为真正的宿主（#3111–#3115、#3120–#3123、#3126）

宿主契约声明自己的能力与附件支持（#3111）；引擎已提交的事件被翻译进远程时间线（#3113），历史投影在其后回放（#3112），引擎命令映射为宿主方法（#3114）。独立运行的 host runner 可以服务已发布的会话（#3115）。

`miao serve --remote-host` 在常驻引擎旁启动这个宿主（#3120），发布归档现在同时携带 `miao-remote` sidecar（#3121）。宿主会向自己的 Hub 账户注册（#3122）。`miao runtime access` 从 stdin 读一条 JSON 请求，解析 0600 权限的注册文件并拒绝非 loopback 端点；宿主提供仅所有者可用的 `POST /access`，支持 status、session、invite、pending、devices、approve、reject、revoke（#3123）。

TUI 窗口也可以自己托管 Remote Control（`miao --remote-host <control.json>`），把窗口拥有的 Runtime 作为 pane 的 `runtime_context` 发布给 mtty，并在窗口停止时删除注册文件（#3126）。mtty 的管理界面因此可以核验它当前连接的窗口，而不是猜测另一个本地 Runtime。

## 更清爽的输入框

运行状态与中断键回到输入框左上角（`Working · 2.1m · Esc interrupt`、`Idle`、`needs approval · bash`），模型与异常提示单独占输入框下方一行，边框不再承载这些文本（#3124）。一轮结束后标题也保持可读（#3117）。

## 侧栏与版本提示

24H 用量表与 SESSION 行使用同样的两列缩进，表头对齐到模型列，并去掉 provider 分组的 `- ` 标记；侧栏不再重复窗口 chrome 已经显示的会话标题与路径（#3125）。TUI 会在启动时和运行中检查新版本（#3116）。

## 修复

- iOS 语音识别改为跟随系统首选语言（规范化为 `zh-CN` 这样的 BCP-47 locale），不再回退到英文（#3130）。
- 提交时为缺失图片读取剪贴板时，不再把读到的文本拼进草稿；孤立图片标记不会再把同一段文字复制进输入框（#3129）。
- 引擎自行接纳的续跑会正确归属到引擎（#3118）。
- 旧进程仍存活时不再迁移存储（#3110）。
- iOS 语音输入可以可靠启动，并解释失败原因（#3127）。
