# miao v0.3.97

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.97.md)

v0.3.97 让自动压缩之后的上下文数字说真话。

## 压缩之后的那一行

长会话会自动压缩，压缩本身一直有效：61.4 万 token 的提示会变成 2.2 万。但压缩之后的那一轮仍按压缩**之前**报告的数字规划，侧栏于是把旧数字显示在一个小得多的请求旁边，看起来像压缩没有释放任何空间，后续判断也沿用了那个旧值。

现在锚点会忽略最新压缩之前的 usage 报告；usage 事件上报的是该次请求实际携带的占用（取自 provider 自己的计数）；窗口来自模型自身的限制，因此压缩后紧接着的那一轮也能标出它实际运行的输入上限。
