# miao v0.4.13

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.4.13.md)

v0.4.13 把默认页面恢复到 0.4.9 的配色，转录不再在终端窗口里显示成另一种颜色的方块。同时给折叠的工具输出留出可读宽度，并让超出窗口的会话继续可运行。

## 页面重新和窗口一致

0.4.10 把默认深色调色板换成了中性石墨色阶。页面于是画成 `#212121`，而终端自身的边框仍是 `#2e3440`，每条窗格边缘都成了可见的接缝。

之后的改动又让页面直接采用宿主为窗格卡片播报的颜色。在给窗格留内边距的终端里，那个颜色是内边距的颜色，不是页面该用的颜色，于是转录成了两侧之外第三种色块。

两处改动都已回退：默认深色主题回到 Nord 系调色板，`#2e3440` 底色配淡紫、青色与琥珀强调色，页面也不再从环境变量改写自己。你自己选的主题不受影响，单独调整过的 diff 行底色与行号颜色保留原值。

## 折叠的工具输出仍然可读

折叠的工具结果里超宽的一行现在按列宽裁剪，并注明 `long lines clipped`，折叠结果保留三行预算。连续调用之间重新用空行分隔，每次调用都是页面底色上的纯文本，而不是实心徽标。

## 超出窗口的会话继续推进

上下文已经超过模型窗口的会话重新可以继续，而不是卡在无法开始下一轮。等待中的任务在等待结束后会立刻清掉暂停行。
