# miao v0.3.83

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.83.md)

v0.3.83 让读者留在原处：翻到历史里的对话，不再因为后台投影到达而被拉回最新行。

## 翻历史不再被拉回底部

引擎每次只投影会话的“最新窗口”。当读者已经翻进历史时，这个投影会替换掉已加载的更早页面，并把视口夹到窗口末尾——也就是最新内容。于是每一次后台投影（提交的一步、传输重同步、静默恢复）都会把视图拉回底部。

现在，脱离尾部的对话会保留已加载的行，并挂起新投影，直到读者用 `End` 或滚动回到底部。挂起期间输入框与状态行仍照常更新。
