# miao v0.5.2

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.2.zh.md)

v0.5.2 makes the model catalog keep up between releases, and closes the gap
where a subscription plan serves a model the catalog does not list yet. It also
carries the TUI and engine fixes that landed after the 0.5.1 tag.

## The catalog refreshes itself

The product used to read only a snapshot on disk. The site rebuilds its catalog
daily, but a machine saw a new model only when it upgraded, and the shipped
snapshot kept whatever it was built with.

miao now fetches `https://mtty.dev/models/api.json` (the URL the site actually
serves — `/models` is the documentation page), revalidates it once a day with
`If-None-Match`, and caches it atomically at
`$XDG_CACHE_HOME/miao/models.json`. An unchanged catalog answers `304` and
transfers nothing. A body that is not a catalog never replaces the file on
disk, and a machine that cannot reach the site keeps the snapshot the install
shipped.

`miao models --refresh` fetches on the spot. The terminal UI and `miao serve`
also refresh in the background, so a long-lived process picks a new model up
without a restart-time download.

## A plan's own model list

A subscription plan can serve models the catalog has not listed yet. For every
OpenAI-compatible provider this machine holds a key for, miao now reads the
provider's own `/models` endpoint every six hours and adds the ids the catalog
misses.

Discovery only adds ids to providers the catalog already names — it never
invents a provider and never overrides an entry. A discovered model carries no
declared context window or price until the catalog has one, and the maintained
overlay runs after discovery, so a real entry always wins.

GLM-5.4 arrived exactly this way: the coding-plan endpoint served it before the
catalog carried it. The catalog now carries it (1M window, 128K output,
text/image/video/pdf input), so 0.5.2 also removes the temporary overlay entry
written for it — the catalog's own entry is now the source.

## Also in this release

- The landing header stays with the first turn instead of the transcript
  scrolling over it.
- A streaming edit waits for the committed diff, so the temporary diff no
  longer flashes before the real one.
- The composer always names its state.
- A session's `git` commands stay inside its own worktree instead of being
  refused for naming a path under the checkout.
- A weekly `catalog-drift` workflow compares the self-maintained overlay with
  the served catalog: an entry the catalog has caught up with fails the run, and
  a partly redundant one is printed for review.

## Verification

- `cargo test --lib`: 626 passed in `miao-engine`.
- `catalog_refresh`: 5 cases (200 + `ETag`, 304 without a rewrite, TTL without a
  request, a non-catalog body keeping the previous file, an unreachable source).
- `model_discovery`: 5 cases (id shapes, URL join, merge boundaries, the
  authenticated probe against a local server).
- End to end on a build host: `miao models --refresh` wrote 327 providers and
  10,228 models, and the second run reported `catalog is current`.
- The drift check against the live catalog: green, with no overlay addition or
  field trim still needed.
- `cargo fmt --check` and `cargo clippy --all-targets -- -D warnings` for
  `miao-engine` and `miao-cli`.
