# miao v0.3.77

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.77.md)

## 修复

- **长会话重新会自动压缩了。** 压缩触发器没有复用请求边界已经使用的输入上限，而是重新解析原始模型窗口，于是 1M 窗口、393K 输入的会话被算出 880K 余量，永远不触发压缩：每条提示都在重发整段历史，而界面显示 94%。现在触发器、请求边界与百分比共用同一组上限（#3078）。
- **各端上下文百分比一致。** 桌面与 Web 端把缓存读写叠加在输入 token 上、再除以原始窗口，同一会话显示 120% 而 TUI 显示 16%。两端现在都读取引擎下发的 `contextBudget`（#3079）。
- **第二张截图可以粘贴了。** 剪贴板交接文件不再在首次读取后删除：按内容哈希每张图只服务一次，宿主继续重写该文件，第二张图不再依赖可能被 pane 拒绝的平台回退（#3080）。
