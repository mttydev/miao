# miao v0.5.15

[English](https://github.com/mttydev/miao/blob/main/docs/releases/v0.5.15.md)

v0.5.15 是一个修复版本：同一仓库的两个会话重新能互相找到；退出横幅也不会再把旧屏文字粘进 `-s` 的命令里。

## 同伴按项目归属，而非 worktree

0.5.0 起，同一检出里的第二个会话会被放进自己的 `.miao-worktrees/<id>` 树，而 `send_message`、`read_session_context`、`list_sessions` 比较的正是这个放置 root。于是同一仓库的两个会话互相看不到：每个 worktree 都被当成了独立项目。

现在项目身份是同一仓库所有 worktree 共享的检出（`git rev-parse --git-common-dir`），在会话放置时记录。启动时会回填身份出现之前创建的会话；不在 git 仓库里的目录以自身为项目。同伴邮件、上下文读取、会话列表以及存储层的投递边界都按项目比较，未回填的行仍回落到放置 root。

## 退出横幅可以放心复制

退出时横幅会覆盖恢复屏幕上残留的内容，比横幅短的行尾巴会留在右侧：复制出的 `miao -s` 可能变成 `ses_…19800e`，而真实 id 是 `ses_…1980`。现在每行都擦到行尾，并整块一次写出。

## 验证

- worktree：链接 worktree 与其检出回答同一个项目。
- 同伴：同一项目的两个 worktree 之间邮件可达，其他项目在存储层被拒，`list_sessions` 能列出另一 worktree 的同伴。
- 651 个 `miao-engine` lib 测试、865 个 `miao-tui` lib 测试、13 个 session-messaging 测试与 TUI 冒烟套件通过；clippy 无告警。
