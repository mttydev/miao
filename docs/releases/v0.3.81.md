# miao v0.3.81

[简体中文](https://github.com/mttydev/miao/blob/main/docs/releases/v0.3.81.zh.md)

v0.3.81 turns the native iOS client into a real remote workbench, opens long Sessions at their tail instead of replaying them, and keeps code colours inside TUI diff views.

## A remote workbench on iPhone and iPad (#3108)

The iOS app now keeps the last tab, computer and Session, opens the sidebar by default on iPad, and supports hardware-keyboard shortcuts. The Session list shows relative activity, pending approvals and questions, pinned state and a non-muted attention count; the icon badge follows the same aggregate. Pull-to-refresh, automatic paging and swipe actions replace hunting through long-press menus.

New Sessions open immediately, and prompts are shown locally while the host confirms admission. A failed or uncertain send keeps the bubble: a transport failure can be retried with the same operation id, while an uncertain result is reconciled without resending. Connection, error and pending banners stay visible while the transcript scrolls, and stop lives in the navigation bar.

The transcript now shows tool status, duration and failures; assistant messages expose tokens, cost and time-to-first-token; diffs group by file with +/- counts. Transcripts can be copied or exported. Message search runs off the main actor, voice input has a duration, cancel and locale selection plus audio-interruption handling, notification opening shows progress, `miao://session/<host>/<session>` links open a Session directly, and per-Session mute is available locally.

Attachments and command shortcuts are capability-gated: they appear only when the connected host advertises them. The optional prompt attachment contract is documented in `RPC-PROTOCOL.md`; hosts that do not advertise it keep the text-only behaviour.

## Open a long Session at its tail (#3106)

Opening a Session used to replay the entire event journal from sequence zero. A five-day Session with 13,612 messages and 89,414 events did not finish opening in two minutes. The TUI now reads one page of the newest messages and replays only the events in that window; scrolling up asks for the page behind the loaded window. The same Session opens with 200 messages, 338 KB and 1,302 events instead of 21.7 MB and 89,414 events.

## Diff colours belong to the code (#3107)

The TUI changes view painted only the `+`/`-` markers, leaving the code one flat colour. Both marker and body now share the transcript's syntax renderer, and a changed row carries its diff band to the pane edge. Edit diffs also open by default in the desktop timeline.
